# CLAUDE.md — kgsm-dns

Guidance for working in this repo. The design's authority is `cluster-dns-plan.md` at the workspace
root; this file is how the code implementing it is laid out and what must stay true of it.

## What this is

One cluster anchor (`kgsm-dns`, Native AOT, systemd) holding the `dns` capability, plus one package
(`TheKrystalShip.KGSM.Dns`) that every member compiles against. The anchor is the only member holding
a credential for the zone. Every other member asks it for a name.

```
src/Dns/          the names, the bus messages, and a member's half: naming, certificates, serving
src/Dns.Anchor/   the daemon: registry, provider, reconciler, capability standing, ACME issuance
```

## The invariants

These are the reason the design is safe. Breaking one is not a regression in a feature — it is the
component becoming something else.

- **A name points at where its own holder is reached, and nowhere else.** A node name at that node's
  public host, a capability name and its aliases at its assigned holder's host, a game name and its
  aliases at its node's name. A host is a hostname (a `CNAME`, normally a dynamic-DNS name) or a
  public address; `PublicHost` refuses anything nobody outside could reach, and anything inside the
  cluster's own bases.
- **Only nodes hold node names.** An anchor is reached by its capability, so a machine carries one node
  name however many anchors run on it. A pinned name is reserved for its member before it joins.
- **Nothing outside the three bases is written, except a capability alias an administrator named.**
  `ClusterBases.Owns` is the test for the bases, and it is a test on the name rather than a judgement
  about intent. The top of the zone is not a base: it holds the operator's own names, which a member may
  state as its public host. A capability alias lives there by an administrator's word alone —
  `ClusterBases.HoldsAlias` is its shape, and a record of that shape is the cluster's only when it
  carries a `capability-alias` mark.
- **A record without this cluster's mark is not this cluster's.** Never edited, never deleted, never
  counted as satisfying a name. A person is free to make a record that looks exactly like one of
  ours.
- **The registry is desired state; the zone is reconciled to it.** One direction. The single thing the
  provider is authoritative for is its own handle for a record.
- **Recovery happens once, before anything is claimed, on an empty registry.** Once a member has read
  its registry, empty means everything was released — which looks identical to an unbuilt registry
  and must not be answered the same way, or a released name would be rebuilt from the record it is
  about to withdraw. And it precedes every claim: a claim against an unread registry draws a new name
  for a member the zone already names, and the next pass withdraws the one it is reached at.
- **A name is sticky.** A member keeps it across restarts and address changes. Certificates, game
  names and people's bookmarks all name it.
- **Nothing is published against a guess.** A member with no usable public host, or a label whose whole
  numbered series is held, is a blocked row carrying the reason, and a record the name held before it
  was blocked is withdrawn. A name pointing at a guess is worse than a name that does not resolve.
- **Not heard is not told otherwise.** A capability holder the anchor has no statement from keeps a
  name it already held where it was — every member is unheard from for a moment after the capability
  moves. A name moving to such a holder is withdrawn until it speaks. On a member, an empty set of
  names withdraws its site only once the anchor has answered since the member started.
- **A private key never leaves the member that made it.** A signing request and a certificate are the
  only things that travel. The anchor's own ACME account key is generated by the holder and never
  copied, so failover moves no secret.
- **A certificate is ordered only for a name its requester holds, published, and only that name.**
  `CsrHandler` checks the registry row; `SigningRequestCheck` refuses a request naming anything else,
  because the issuer certifies every name in a request the zone can prove.
- **A generated site carries names and certificate paths, nothing else.** Everything about how a request
  is handled is the component's own `.locations` file, installed with it.
- **Standing by means writing nothing.** Two members writing one zone would each reconcile the
  other's records away, so a member that is not the holder does not touch the provider at all.

## Conventions

- **Native AOT, so no reflection.** Wire shapes go through a source-generated `JsonSerializerContext`;
  storage is raw ADO `Microsoft.Data.Sqlite`. Publish must stay at zero ILC warnings:
  `dotnet publish src/Dns.Anchor/Anchor.csproj -c Release -r linux-x64`.
- **The settings file is the floor.** `kgsm-dns.settings.json` declares the whole surface, one key per
  `AnchorSettings` property and per `[ConfigField]`. A knob that exists in one place and not the others
  fails the build, and an environment variable naming a key the file does not declare sets nothing.
- **`AnchorSettings` is what was written; `AnchorOptions` is what the daemon runs on.** Clamping and
  defaulting happen in the projection between them.
- **The descriptor is generated, never edited.** `deploy/kgsm-dns.anchor.json` is rewritten by every
  build from `AnchorSettings` and `Descriptor.cs`. The `.anchor.json` suffix routes it to
  `/var/lib/kgsm/anchors/`, which is not where a node's leaves are scanned for.
- **Logging is `AddSystemdConsole()`** with the ecosystem's level convention.
- **The browser surface is behind the cluster's session, each route checking its own `dns:*` action.**
  `Status/StatusEndpoints` serves `/api/v1/cluster/dns` (`dns:names.read`) and its `/events`
  (`dns:journal.read`); `Status/AdminEndpoints` serves the zone check (`dns:zone.check`), the certificate
  renewal (`dns:certificates.renew`) and the alias routes (`dns:aliases.write`); `/me/access` lists what
  the caller holds of them. Each route declares its action as `DnsAction` metadata, which its handler
  reads to enforce and `GET /operations` (`Access/DnsOperations`) publishes, so a client names no
  `dns:*` action of its own; a route checking an action it does not declare is one no client can see.
  `Access/ClusterBearer` admits a caller through the shared
  `ClusterSessionValidation` (its own half is a key that signs nothing), resolves the person in this
  anchor's own authority replica (`OwnedReplicaFile` at `Dns:AccountsPath`, filled by
  `AddAuthorityReplica()`) and evaluates the route's action across the cluster on every request. The
  actions are declared in `Access/DnsActions` and reach the catalog through the manifest this anchor
  reports itself (`AuthorityReporter`, `/var/lib/kgsm/anchors/actions/dns-anchor.json`). Nothing reachable from a browser
  writes the zone, the registry or the issuer directly: a write route calls the same `NameService`,
  `ClusterMembershipWorker` and `CertificateKeeper` the zone pass itself uses, under the same entitlement
  checks, and refuses outright on a member standing by for the capability.
- **The journal records transitions, never passes.** `RecordReconciler.Pass.Changes` carries every
  change a pass made; a pass that fails partway hands what it already did to `TakeUnreported`, because
  the zone holds it either way. The zone's own standing is journalled only when it flips.

## Testing

`dotnet test kgsm-dns.slnx -c Release`. The anchor's tests run the reconciler against an in-memory
zone that refuses a duplicate name the way the real provider does — a fake that allowed duplicates
would pass tests the live provider fails, and that refusal is the lock two claims for one name race
against.

## Version tracking

The version lives in `src/Dns.Anchor/Anchor.csproj` and is read from there by `deploy/version.sh`, the
package and the release workflow. `src/Dns/Dns.csproj` versions on its own schedule, as a published
package. A version bump ships with its `CHANGELOG.md` entry in the same commit, and that commit is
tagged `v<version>`.
